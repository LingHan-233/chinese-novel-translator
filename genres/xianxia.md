Use the established fan-translation vocabulary unless the glossary says otherwise:

- Sect titles: 师父/师尊 → Master; 师兄 → Senior Brother; 师姐 → Senior Sister; 师弟 → Junior Brother; 师妹 → Junior Sister; 掌门/宗主 → Sect Leader; 长老 → Elder; 前辈 → Senior; 道友 → Fellow Daoist.
- Self-reference with attitude (本座, 老夫, 本尊, 在下, 晚辈, 老子): usually just "I", with the attitude carried by the wording (imperious, humble, crude). Use a fixed phrase ("this old man", "this junior") only if the character table says it is that character's signature.
- Common terms: 修为 → cultivation; 境界 → realm; 突破 → breakthrough; 灵气 → spiritual energy (or qi); 灵石 → spirit stones; 丹药 → pills; 法宝 → treasure; 功法 → cultivation technique; 秘境 → secret realm; 渡劫 → tribulation; 天骄 → prodigy; 宗门 → sect.
- Realms (练气, 筑基, 金丹, 元婴...) → follow the glossary; common choices are Qi Refining, Foundation Establishment, Core Formation, Nascent Soul.
- Time: 一炷香 → "the time it takes an incense stick to burn" when the timing matters, otherwise "a short while".
- Fight scenes: short, fast sentences. Don't list every flourish of a stacked four-character description; keep the strongest image.
- Face-slapping (打脸), arrogant young masters, "courting death" (找死) taunts: these are genre pleasures — keep the swagger and the payoff line sharp.
