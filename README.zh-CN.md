# 中文小说翻译器（中译英）

用你自己的 AI agent，把中文网文翻成英文来读。

把一本中文小说（`.txt` 或 `.epub`）交给 agent，它会一段一段地翻译，最后给你 `.epub`、`.html`、`.md` 三种格式，手机电脑都能读。从第 1 章到第 1000 章人名和术语保持一致，作者的语气和分段节奏保留下来，成语、称谓和网络用语按意思翻，而不是逐字硬翻。

[English README](README.md)

**新增：日语（测试版）。** 也可以翻成日语，建书时加 `--lang ja`。人名和修仙术语保留汉字（转成日文字形）；检查会拦下残留的中文字、照搬成汉字的中文成语、按字面直译的替代词。已在一本修仙小说上实测约 25 个 passage（DeepSeek V4.1 Flash），还没有日语母语读者看过，欢迎反馈。默认仍是英文，英文版的流程没有变化。

## 为什么便宜的模型也能用

Flash 这一档的快速廉价模型，单句翻译不差，但一本长书翻下去容易前后不一致。这个项目不要求模型记住任何东西：

- 脚本把书切成短段落，每一段生成一个小任务文件，里面已经放好这一段需要的人名、角色、网络用语和前情提要。
- 每段翻完，脚本会**自动检查**：段落是否缺失或合并、是否残留中文、是否夹带解说、是否把翻译写成了摘要、人名是否跑偏。模型按清单改完才能进入下一段。
- 模型新定下的译名会存进术语表，之后每一段都会用到。
- 开译之前，模型会对全书做一次**替代词扫描**（用无害的词代替粗俗词的梗，比如用"牛至"代替"牛子"），每个可疑词都结合多处原文判断，避免按字面直译。默认按字面意思处理，拿不准的留给你决定。

检查只管格式和一致性，不管意思：检查通过，不代表每句都理解对了。最能提升质量的是两件事：

- **本书示例**：第一章译完后，挑 2–3 段你喜欢的（或者自己改写），agent 用 `pin` 存下来，之后每一段都会模仿这个语感。
- **复核环节**（默认开启）：每段译完后，agent 对照中文逐段重读，先查意思错误（谁对谁做了什么、否定、是/否、数字、头衔、笑点），再润色英文。在故意埋错的测试里，它抓到了 7 处中的 7 处；关掉复核则全部漏掉。费用约多 70%。`set review spot` 是更省钱的折中，能可靠抓到数字错误，其他错误主要靠运气。

只用便宜模型，得到的是通顺、大体准确、偏朴素的英文。

## 需要准备

- 一个能在你电脑上读写文件、运行命令的 AI agent（例如 Claude Code 这类编程 agent）。
- Python 3.8 或更新版本。不需要安装其他任何东西。

## 安装

对你的 agent 说：

> 下载 https://github.com/LingHan-233/chinese-novel-translator 并安装为 skill，然后阅读它的 SKILL.md。

如果你的 agent 不支持 skill，把文件夹下载到任意位置也可以，让它读 `SKILL.md` 并照做。

## 使用

> 用 chinese-novel-translator 把 `我的小说.txt` 翻译成英文。

agent 会先整理这本书，列出主要角色和术语，**只翻第一章**给你看。你读完可以提修改意见（"老王就叫 Old Wang""语气再随意一点"），满意了再让它继续。随时可以停，下次开新会话接着翻。

## 看不懂英文？让另一个模型来改示例

本书示例对文风影响最大，但你不需要会写英文。第一章译完后，让 agent 挑 2–3 小段（对话、平静叙述、动作各一段），然后另开一个对话，换一个**不同的**模型（最好更强一些，反正只有几段），把原文和译文贴进去，加上这段提示词：

> 你是资深的中译英网络小说编辑。下面是几段中文原文和英文初稿，每段都有 [[P1]] 这样的段落标记。请修改英文：（1）意思必须和中文一致：不漏、不加，谁对谁做了什么、肯定还是否定、数字都不能变。（2）意思忠实，但**不要逐词对应**：读起来要像英文原创小说，没有翻译腔。（3）保持原作语气：搞笑的要好笑，粗口保持粗口，保留原文的"！"和"？"。（4）人名、术语沿用初稿译法。（5）保留段落标记和段落数量。输出两部分：第一部分只放修改后的英文，按标记逐段给出；第二部分**用中文**逐段说明：这段英文现在表达的意思，以及改了什么、为什么。

你只需要看第二部分：它的中文复述和原文对得上，意思就没错。然后把英文交回给 agent，让它用 `pin ... --en` 存起来。

## 目前的测试结果

用便宜模型（DeepSeek V4.1 Flash）在三本网文的第一章上做的小规模测试：

- 译完后故意埋入意思错误：全量复核抓到 7 处中的 7 处；只查约四分之一段落的抽查复核，24 处抓到 6 处。
- 由另一个模型修改的 3 段本书示例，让下一章 76% 的段落向示例的语感靠拢（句子更短、更有生气）；新增十几条规则只改动了 8%。但示例也带来了少量偏差（丢了感叹号、有一处意思被改反），所以复核默认保持开启。

样本很小，请当作方向参考，而不是保证。

## 费用

每段约 1500 个中文字，加上约 2500 token 的说明和上下文：翻译一段大约输入 4000 token、输出 1500 token，默认的复核再加约输入 3000、输出 1500。一本 100 万字的网文约 670 段。agent 每一轮还会重发对话历史，实际会更多，所以**每翻几章就开一个新会话**（agent 会从停下的地方继续）。整本开翻之前，先看看第一章花了多少。

## 请注意

本工具只用于**个人阅读**。请不要发布、分享或出售译文。如果这本书有官方英文版，请支持正版。

## 项目结构

| 路径 | 内容 |
|---|---|
| `SKILL.md` | 给 agent 的操作说明 |
| `scripts/novel.py` | 辅助脚本：切分、任务文件、检查、术语表、生成 EPUB |
| `core/` | 翻译规则、专名处理 |
| `genres/` | 题材说明：仙侠/武侠、都市/系统、历史/官场、通用 |
| `lang/en/` | 英文风格指南和示例译文 |
| `slang/zh_internet_slang.tsv` | 网络用语、网文黑话和谐音/委婉替代词，附建议英文和要避免的字面直译 |
| `templates/` | 空白术语表、角色表、梗概 |
| `tests/sample_book.txt` | 一篇原创的短篇示例，可用来试跑流程 |
| `tests/scan_sample_a.txt`、`tests/scan_sample_b.txt` | 两篇测试替代词扫描用的原创短篇（同样的词，在一篇里是字面意思，在另一篇里是替代梗） |

## 参与贡献

最简单也最有用的贡献：

- **网络用语**：在 `slang/zh_internet_slang.tsv` 里加一行（词、意思、语气、建议英文、处理方式、要避免的字面英文）。谐音/委婉替代词（用无害的词代替粗俗的词，比如用"牛至"代替"牛子"）尤其有用：它们按字面直译读起来也通顺，其他检查都抓不到。
- **示例**：在 `lang/en/examples.md` 加简短的原创中英对照，不要用已出版小说的原文。
- **题材说明**：完善 `genres/*.md`，或新增题材（言情、历史、悬疑……）。
