Aim: fluent modern Japanese fiction, the way a well-edited web novel (なろう系 / 中華ファンタジー翻訳) reads. Plain-style narration (だ・である), the same point of view as the original. Natural spoken Japanese in dialogue.

Avoid these translationese habits — use the natural alternative:

| Chinese habit | Don't write | Write |
|---|---|---|
| 他/她 in every sentence | 「彼は…。彼は…。彼は…。」 | leave the subject out when it is clear |
| 一丝 | 「一抹の笑み」 every time | 「かすかに笑った」, or just 「笑った」 |
| 不禁 / 忍不住 | 「思わず」 every time | vary, or drop it |
| 顿时 / 瞬间 | 「その瞬間」「たちまち」 every time | often nothing; let the action be sudden |
| 淡淡道 / 冷冷道 | 「淡々と言った」「冷たく言った」 | let the line carry the tone, or an action beat |
| 冷哼一声 | 「冷たく一声鼻を鳴らした」 | 「ふん、と鼻を鳴らした」 |
| 心中一惊 | 「心中一驚した」 | 「ぎくりとした」「はっとした」 |
| 嘴角微微上扬 | 「口角がわずかに上がった」 | 「口元がほころんだ」 |
| 说道 / 道 | 「〜と言った」 after every line | use it sparingly; action beats or nothing |
| Chinese compounds kept as they are | 「迅速に移動し、攻撃を発動した」 | everyday Japanese verbs: 「素早く動いて斬りかかった」 |
| 立了大功 / 看家本领 / 火烧眉毛 | 「大功一件」「看家の腕」「火が眉毛まで燃えている」 | 「大手柄だ」「十八番の腕」「尻に火がついている」 |
| long の chains | 「宗門の長老の弟子の剣」 | rebuild the phrase |

Keep the energy: ！ only where the original shouts; no ellipsis chains beyond what the original has.
