Japanese readers of 中華ファンタジー know these terms in kanji. Keep them in Japanese form unless the glossary says otherwise:

- Sect titles: 师父 → 師父; 师尊 → 師尊; 师兄 → 師兄; 师姐 → 師姐; 师弟 → 師弟; 师妹 → 師妹; 掌门 → 掌門; 宗主 → 宗主; 长老 → 長老; 前辈 → 先輩; 道友 → 道友.
- Self-reference with attitude (本座, 老夫, 本尊, 在下, 晚辈, 老子): a Japanese first-person word with the same attitude (老夫 → わし, 老子 → 俺様, 晚辈 → 私 with humble wording). Put the choice in the character's note so it stays the same.
- Common terms: 修为 → 修為; 境界 → 境界; 突破 → 突破; 灵气 → 霊気; 灵石 → 霊石; 丹药 → 丹薬; 法宝 → 法宝; 功法 → 功法; 秘境 → 秘境; 渡劫 → 渡劫; 天骄 → 天驕; 宗门 → 宗門.
- Realms (练气, 筑基, 金丹, 元婴, 化神...) → 練気, 築基, 金丹, 元嬰, 化神, or as the glossary says.
- Time: 一炷香 → 「線香が一本燃え尽きるほどの間」 when the timing matters, otherwise 「しばらく」.
- Fight scenes: short, fast sentences. Don't list every flourish of a stacked four-character description; keep the strongest image.
- Face-slapping (打脸), arrogant young masters, "courting death" (找死 → 死にたいらしいな) taunts: these are genre pleasures — keep the swagger and the payoff line sharp.
